WebRTC recorder: connection check

Checks the path from this workstation to the screen recording service, the same way the recorder client does, and measures the connection quality. Test recordings are discarded by the server.

Settings

The page must be opened from the Webitel host (same origin as the API), otherwise the browser blocks the request.
